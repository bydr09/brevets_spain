Política de privacidad

Qué información utiliza esta web, dónde se guarda y qué servicios intervienen al navegar por ella.

Resumen: esta web no tiene cuentas, formularios, publicidad ni analítica propia. No instala cookies. Solo guarda en el navegador una preferencia funcional y utiliza GitHub Pages para alojar la página.

1. Responsable y alcance

Brevets España 2027 es un proyecto informativo independiente alojado en GitHub Pages. No representa al Audax Club Parisien, a los clubes organizadores ni a las entidades cuyos eventos aparecen en el calendario.

Esta política se aplica exclusivamente a esta web. Los sitios enlazados, las páginas de los clubes y los formularios de inscripción tienen sus propias políticas y responsables.

2. Datos utilizados por la web

El proyecto no solicita nombre, correo electrónico, teléfono, ubicación precisa ni datos de inscripción. Tampoco utiliza herramientas propias de analítica, perfiles publicitarios o seguimiento entre sitios.

El calendario se descarga como un archivo JSON público. Las búsquedas y filtros se ejecutan íntegramente en el dispositivo del visitante y no se envían al responsable del proyecto.

3. Almacenamiento local

La web utiliza localStorage para recordar únicamente la última sección visitada mediante la clave brevets-2027-view. Esta preferencia:

  • permanece en el navegador del visitante;
  • no identifica por sí sola a una persona;
  • no se envía al servidor del proyecto;
  • puede eliminarse borrando los datos del sitio desde la configuración del navegador.

La web no crea cookies propias.

4. Servicios externos

GitHub Pages

GitHub aloja y entrega los archivos de la web. Como cualquier servicio web, puede tratar datos técnicos de conexión —por ejemplo, dirección IP, fecha, solicitud y tipo de navegador— para prestar y proteger el servicio. Consulta la declaración de privacidad de GitHub ↗.

Enlaces externos

Los enlaces a clubes, reglamentos y otras fuentes solo transmiten la visita al proveedor correspondiente cuando el visitante decide abrirlos.

5. Finalidad y conservación

La única preferencia gestionada directamente por la aplicación se utiliza para recuperar la última vista elegida. Se conserva en el dispositivo hasta que el visitante borra los datos del sitio. El proyecto no mantiene una base de datos de visitantes.

6. Derechos y contacto

Como la aplicación no recibe ni conserva datos personales proporcionados por el visitante, normalmente no dispone de información sobre la que ejercer derechos de acceso, rectificación o supresión. Las solicitudes relacionadas con datos técnicos tratados por GitHub deben dirigirse a ese proveedor.

Para comunicar un problema relacionado con esta política puede utilizarse el sistema de incidencias del repositorio ↗. Las incidencias son públicas: no deben incluirse contraseñas, documentos, direcciones, teléfonos ni otra información sensible.

7. Cambios en esta política

La política se actualizará si se incorporan formularios, analítica, publicidad, cuentas de usuario u otros tratamientos. La versión vigente es la publicada en esta dirección.
